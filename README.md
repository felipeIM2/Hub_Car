# HubCar Dashboard

This is a Next.js-based web application called "HubCar" that serves as a comprehensive vehicle rental management system.

## Technologies Used

### Frontend Framework
- **Next.js** - React-based framework for production-ready applications
- **React** - JavaScript library for building user interfaces
- **TypeScript** - Typed superset of JavaScript

### Styling
- **Tailwind CSS** - Utility-first CSS framework
- **PostCSS** - CSS processing tool

### UI Components
- **Radix UI** - Unstyled, accessible UI components
- **Lucide React** - Icon library

### State Management & Hooks
- **React Hook Form** - Performant, flexible forms with easy validation
- **Zod** - TypeScript-first schema declaration and validation library
- **Next Themes** - Theme provider for Next.js applications

### Development Tools
- **ESLint** - JavaScript/TypeScript linting utility
- **Prettier** - Code formatter

### Package Management
- **pnpm** - Fast, disk space efficient package manager

### Other Libraries
- **Date-fns** - Date utility library
- **Recharts** - Charting library built on D3 and React components
- **Class Variance Authority** - Utility for creating class variants
- **Tailwind Merge** - Utility function to efficiently merge Tailwind CSS classes
- **clsx** - Utility for constructing className strings conditionally

## Application Features

The application includes modules for:
- Dashboard overview
- Client management
- Vehicle inventory
- Parts tracking
- Rental transactions (leases)
- Maintenance records
- Contracts management
- System configuration

With support for both light and dark themes.# HubCar
